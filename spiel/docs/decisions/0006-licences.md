# 0006 Licences: MIT for code, CC BY 4.0 for content

- Question: under what terms is the game published?
- Options: all rights reserved until the course is paid; one open licence for everything; a code licence and a content licence.
- Choice: MIT for the code (`index.html`, `css/`, `js/spiel.js`, `scripts/`), CC BY 4.0 for the exercise texts and the data files under `data/`, attribution "gitklar von bitz, Lars Schöbitz GmbH". The vendored parser keeps its own MIT licence. The glossary copy follows Glosario (The Carpentries, CC BY 4.0) in substance, in its own German words, as the website states.
- Why: the owner's earlier course material is open educational material, and the game is small enough that openness costs nothing and lets other courses reuse the exercise model. CC BY on the content keeps the attribution to the course, which is the brand surface.
- Consequences: the website repository has no licence file yet; when it gets one, the glossary copy here should carry the same terms. A paid cohort can use the game without changing anything.
